## 실제 공개 API 연결 검사 · 단위 테스트와 별도

- 한국 노트북 직접: 공개 품목202106092의 DUR4유형 모두 정상 빈 응답. 공개 품목202200407의 AGE1건은 전체 수집·행 검증 통과, 공식 갱신일2025-11-10. 노인/임부는 정상 빈 응답이었다.
- 기존 노트북 Python 중계만 최신 코드로 재시작했다. 기록된 실행 파일·명령을 대조한 뒤 해당 프로세스만 바꿨고 터널 호스트·별도 토큰은 유지했다.
- 동일 임시 HTTPS 중계 경유: 이름 검색의 실제 후보 코드202106092, e약은요1건/updateDe2026-06-29, DUR4유형 정상 빈 응답, 품목202200407의 AGE1건/갱신일2025-11-10을 확인했다. 공식 키 없는 클라이언트가 별도 토큰으로 조회했다.
- 원장·Calendar는 연결 검사에서 변경하지 않았다. 실제 키·토큰·주소·헤더·전체 요청 URL·상류 오류 원문을 출력하지 않았다. 빈 응답은 개인의 복용 안전 판정이 아니다.
